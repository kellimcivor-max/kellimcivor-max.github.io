The shift

AI coding is where token budgets go to die.

As teams move from lightweight chat into coding, coworking, and automation, token consumption compounds fast. Average monthly AI token spend grew roughly 13× between January 2025 and January 2026 across 50,000+ businesses, and engineering teams have reported burning through an entire year's AI-coding budget in the first few months of the year.

Most of those tokens are never user-typed text. They're system prompts, tool schemas, retrieved documents, tool calls, code execution, and reasoning loops — the machinery of getting to an answer.

The reframe

The question isn't the price per token. It's the yield per token.

Token efficiency is an architecture problem, not just a model-pricing problem. How you design the context layer, the routing, and the harness determines how much work each token actually does. Glean's language-to-code capability is built to raise that yield.

How the coding harness works

Do the expensive thinking once, in the right place.

01

Code execution, not tool ping-pong

Instead of the model calling one tool at a time and re-reading every result, the harness executes work as code in a sandbox. A workflow that traditionally streams hundreds of thousands of characters of raw tool output back into context can collapse to a couple thousand tokens.

02

Warm-start discovery

Rather than front-loading the entire catalog of tools and skills, the harness injects only the handful most relevant to the request. The model starts with a lean, focused surface and discovers more only if it needs to.

03

The filesystem is the memory

Full outputs are written to files; only truncated previews live in the model's context window. The model writes code to dig deeper into a file only when the task actually requires it — instead of paying to hold everything in the prompt.

04

A leaner prompt

A materially smaller system prompt with instructions moved into on-demand skills means fewer fixed tokens on every single request — the cost you pay before the model has done any useful work.

Why the context layer matters

Retrieve precisely instead of over-fetching.

Without a strong index, AI compensates by over-fetching data across many tool calls and burning reasoning loops to synthesize it. That dilutes the context window, invites contradictory data, and inflates token cost at every step. Glean's index produces ranked, permission-filtered, chunked results directly — so the model sees the right context the first time.

Model choice

The right model for the job.

Routing every step of an agentic workflow through a frontier model means paying frontier prices for work that doesn't need frontier intelligence. Glean is model-agnostic — 30+ open and proprietary models through one key — so each step goes to the model with the best price-performance for that task.
